Modelo semántico · DAX

El código queda tuyo.

Cada medida documentada y versionada. Argentina = separador ; y formato regional. Cero magia oculta.

— measures/01_ventas.dax
// Ventas netas del período seleccionado
VAR _ventas_brutas = SUMX( Hechos[Ventas];
    Hechos[cantidad] * Hechos[precio_unit] )
VAR _bonif = SUM( Hechos[bonificacion] )
RETURN _ventas_brutas - _bonif

// % Margen sobre costo
VAR _costo = SUMX( Hechos[Ventas];
    Hechos[cantidad] * RELATED( Productos[costo] ) )
RETURN DIVIDE( [Ventas netas] - _costo; [Ventas netas] )
