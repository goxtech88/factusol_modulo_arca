Bajo el capó · cómo está hecho

La base de datos queda tuya.

Factusol usa MS Access (.mdb). Eso significa que vos sos dueño de tus datos — los podemos leer desde Power BI, Python o cualquier herramienta con ODBC. Cero lock-in.

— ejemplo: extraer ventas del último mes con pyodbc
import pyodbc
conn = pyodbc.connect(
    r"Driver={Microsoft Access Driver (*.mdb, *.accdb)};"
    r"DBQ=C:\Factusol\datos\FAC.mdb;"
)
cur = conn.cursor()
cur.execute("SELECT NUMFAC, FECFAC, CLIFAC, TOTFAC "
    "FROM F_FAC WHERE FECFAC >= ?", ultimo_mes)
for row in cur:
    print(row.NUMFAC, row.CLIFAC, row.TOTFAC)

FAQ · lo más preguntado

Preguntas frecuentes.

¿Cuánto cuesta Factusol?

Factusol tiene una versión Evolution gratuita (limitada en clientes/artículos) y versiones de pago de Sage. Nosotros cobramos por la implementación, soporte y módulos custom. La licencia se paga aparte directo a Sage si pasás a la versión paga.

¿Funciona con facturación electrónica AFIP?

Sí — con el Módulo ARCA Sync que desarrollamos. Validás la factura desde Factusol y el CAE + QR + código de barras vuelve automáticamente al sistema en menos de 10 segundos. Sin Token Fiscal, sin doble tipeo.

¿Cuántos puntos de venta soporta?

Tantos como necesites. Configuramos hasta 99 PV con numeradores independientes. El Módulo ARCA gestiona los CAE de cada PV por separado.

¿Es multi-usuario en red?

Sí. Compartís la base en red (servidor o NAS) y configurás permisos por usuario. Si la operación crece, te recomendamos pasar la base a SQL Server (Factusol soporta ambos motores).

¿Se conecta con Tienda Nube o Mercado Libre?

Vía API. No es una integración nativa de Factusol, pero la podemos armar como módulo custom: cada pedido del ecommerce se factura automáticamente desde Factusol y el stock se sincroniza.

¿Puedo migrar desde Tango / Bejerman / sistema propio?

Sí. Migramos artículos, clientes, proveedores, saldos contables y movimientos históricos. El proceso lleva 1-2 semanas según el sistema origen y el volumen de datos.

¿Hay soporte oficial Sage en Argentina?

Sage opera desde España y el soporte oficial está limitado para AR. Por eso somos partners locales: cubrimos lo que el soporte oficial no cubre + adaptaciones argentinas + módulos custom.
