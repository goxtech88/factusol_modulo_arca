El problema

Cada venta en Factusol se carga 2 veces: una en tu ERP y otra en el portal de ARCA para sacar el CAE. Pegás los datos, copiás de vuelta el CAE al PDF, archivás. Tiempo perdido + errores humanos + lotes pendientes al cierre del día.

La solución

El módulo lee Factusol → pide CAE a ARCA → escribe el resultado de vuelta en Factusol. Vos seguís facturando como siempre, la impresión y el PDF salen del mismo Factusol pero ya con CAE, QR y código de barras AFIP.

Capacidades

Pensado para facturar más con menos clicks.

✓

Multi punto de venta

Configurás varios PV de AFIP (Factusol + TPV Sol) con tipos de comprobante A/B/C diferenciados.

✓

Multi usuario

Usuarios con permisos por punto de venta. Cada uno valida solo lo que le corresponde.

✓

Auto-validación por forma de pago

Background loop cada 60s detecta facturas nuevas y las valida solas (filtrable por forma de pago).

✓

Notas de Crédito

NC A/B/C asociadas al comprobante original vía AgregarCmpAsoc de WSFEv1.

✓

QR + Código de Barras AFIP

QR reglamentario y cadena CUIT+TipoCbte+PV+CAE+Vto se escriben en Factusol para imprimir.

✓

Sin Token Fiscal

Autenticación con certificado PEM estándar de ARCA. No requiere hardware ni instalación de drivers.

✓

Auto-ajuste de fecha

Si una factura tiene fecha fuera del rango AFIP (±5 días), el módulo la ajusta automáticamente.

✓

Updater automático

El propio módulo descarga las versiones nuevas y se actualiza preservando tu config y licencias.
